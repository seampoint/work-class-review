# Review findings and contributions

The current release is an open review candidate. Seampoint is asking outside reviewers to report technical findings, not to contribute specification text or source code.

Review findings should cite the candidate identity and pin, the document and paragraph, the exact input, the governing rule, the expected result and the practical effect. Classify each finding as a specification gap, an implementation defect, an evidence gap or a host obligation.

Do not submit pull requests, replacement wording, code or other material intended for inclusion. Mark each report “Review feedback, not a contribution.” Seampoint will not incorporate outside material during this phase and may ask a reviewer to restate a report that includes proposed text or code. Seampoint will not accept outside contributions until it publishes a contribution policy, governance process and contributor agreement consistent with the Community Specification License 1.0.

Any later contribution process will require an affirmative act accepting its terms.
