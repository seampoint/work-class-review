## Pre-comparison clarifications

Mandatory initial-event targets are required in every completing execution, respecting every parallel branch and its join. First-withholding requirement selectors resolve against the exact selected-step authority envelope at proposal because the definition contains only its identifier. Initial anchor binding and time failures have explicit refusal codes. Failed combined closures retain original facts and expiry evidence but create no new successors or obligations, including prospective overdue targets. The combined runtime inventory bound records a DEADLINE_RECORDS limit stop on admitted facts. Complete admitted CLOCK events are retained for exact restart reconstruction, including unused activation_clocks after a failed closure. These decisions preceded the first consumer run and were applied to the independent constructors.

## Implementation review clarification

The final review exposed ambiguous unavailable-clock consistency and semantic refusal codes. TIME-003 now explicitly chooses DIGEST_MISMATCH for a corrupted native record digest, DEFINITION_INVALID for resolved static time/binding type errors, BINDING_MISMATCH for a different native field-name inventory and TYPE_INVALID for dynamic typed-value errors. TIME-006 now rejects submitted unavailability that contradicts a latest retained available clock, after embedded authority admission errors. Missing, unavailable or conflicting retained time can project to authority UNAVAILABLE, whose closed schema has no separate conflicting alternative. Historical validation uses the original preceding checkpoint. These clarifications change the candidate pin; earlier results remain at their execution pin.
